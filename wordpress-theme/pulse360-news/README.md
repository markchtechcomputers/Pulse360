# Pulse360 News — Kadence Child Theme

Responsive editorial WordPress child theme for the Pulse360 news brand. It is designed for Kenyan and international news, sports, music, entertainment, artist profiles and culture coverage.

## Included
- Homepage lead story, secondary stories and latest stories
- Optional homepage sections for categories with slugs `news`, `sports`, and `entertainment`
- Responsive story cards, featured images, author/date metadata
- Article page, archive/category/tag/author listings and search results
- Styling for desktop, tablet and mobile layouts

## Install
1. Install and activate the Kadence parent theme (the supplied `kadence.1.5.2.zip`).
2. Zip the contents of this folder as `pulse360-news.zip`, preserving `style.css` and `functions.php` at the ZIP root, then upload in **Appearance → Themes → Add New → Upload Theme**.
3. Activate **Pulse360 News**.
4. Create WordPress categories with slugs `news`, `sports`, and `entertainment`; add featured images and publish articles.
5. In **Settings → Reading**, choose a static homepage if you want to use the custom front-page layout.

## Notes
This is a theme layer, not a complete hosted website or a custom publishing backend. Newsletter styling is a navigation call-to-action only; it does not collect email addresses. WordPress remains responsible for posts, media, users, comments, SEO plugins and publishing workflows.
